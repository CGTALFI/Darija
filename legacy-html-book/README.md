# Manuel de Darija

Methode personnelle d'apprentissage du **darija marocain** (arabe marocain), construite comme un vrai livre numerique.

**Origines ciblees :** Agadir/Souss - Casablanca - Amizmiz/Atlas

## Consulter en ligne

**https://cgtalfi.github.io/Darija/**

Optimise pour smartphone : ajouter a l'ecran d'accueil pour une experience type application.

## Contenu

| Chapitre | Sujet |
|---|---|
| I | Phonetique — appareil phonatoire, consonnes, emphatiques, voyelles, arabizi |
| II | Les bases — salutations, pronoms, present, futur, negation |
| III | Dialogues — amis, famille, collegues, inconnus (4 registres) |
| IV | Culture marocaine — histoire, geographie, linguistique, gastronomie |
| V | Exercices & corriges — auto-evaluation sur les 4 chapitres |
| Annexe | Ecriture & calligraphie arabe |
| Ressources | Chaines video, sites, apps pour apprendre |

## Particularites

- Chaque mot en **arabe + arabizi (chiffres 2,3,5,7,9) + prononciation FR + API**
- Schemas SVG anatomiques de l'appareil phonatoire
- Encadres : A retenir, Astuce, Piege, Note regionale
- Notes regionales Agadir / Casablanca / Amizmiz
- Design oriental (zellige, palette ivoire/vert/terracotta/or)
- Imprimable en PDF (menu Imprimer du navigateur)

Ouvrir `index.html` dans un navigateur. Aucune dependance, aucun serveur requis.
